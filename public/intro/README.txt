FOTO UNTUK LAYAR INTRO / SELAMAT DATANG
=======================================

Simpan 4 foto Karinakas di folder ini (public/intro/) dengan nama PERSIS
berikut. Setiap foto tampil di satu bagian cerita saat digulir:

    karinakas-1.jpg  -> Bagian "Pemeriksaan Kesehatan Rutin"
                        (foto cek tekanan darah bapak lansia)

    karinakas-2.jpg  -> Bagian "Pemantauan Kesehatan Berkala"
                        (foto ibu lansia diperiksa di posyandu + buku catatan)

    karinakas-3.jpg  -> Bagian "Kunjungan & Pendampingan"
                        (foto kunjungan/ngobrol dengan warga lansia)

    karinakas-4.jpg  -> Bagian "Perawatan Penuh Kasih"
                        (foto merawat/menggunting kuku ibu lansia)

Tips:
- Nama file harus sama persis (huruf kecil, .jpg).
- Foto boleh portrait atau landscape; otomatis dipotong rapi (object-fit cover).
- Selama file belum ada, sistem memakai foto hero bawaan agar tetap rapi.
- Untuk mengubah teks/urutan bagian, edit array STORY di:
    src/components/IntroScreen.jsx
